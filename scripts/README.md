# Knowledge Base Sources

Place your TB medical guideline documents inside the sources/ directory.

### Supported File Formats
- **PDF** (`.pdf`) - Automatically loaded and parsed page-by-page.
- **Markdown** (`.md`) - Loaded as UTF-8 encoded text.
- **Plain Text** (`.txt`) - Loaded as UTF-8 encoded text.

---

### Recommended Sources
- WHO TB Guidelines: https://www.who.int/publications/i/item/9789240048126
- CDC TB Guidelines: https://www.cdc.gov/tb/
- NIH TB Information: https://www.nhlbi.nih.gov/

### File Naming Convention
Use a clear naming structure for organizational clarity:
* Format: `source_category_title.<extension>`
* Example: `who_guideline_symptom-screening.md`
* Example: `indonesia_tbc_gambaran_diagnosis.pdf`
